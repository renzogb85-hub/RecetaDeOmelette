# Simple Omelette Recipe

Una página web de receta diseñada y desarrollada como una maquetación responsiva basada en un desafío de Frontend Mentor.

## Descripción

Este proyecto presenta una receta clásica de omelette con:

- cabecera con imagen de la preparación
- bloque de tiempo de preparación
- lista de ingredientes
- instrucciones paso a paso
- sección de nutrición
- diseño adaptable para desktop y mobile

La interfaz está construida con HTML y CSS puro, manteniendo una estética cálida y elegante inspirada en el diseño original del reto.

## Cómo ejecutar el proyecto

No requiere dependencias ni compilación. Puedes abrir el archivo `index.html` directamente en tu navegador o servirlo localmente con un servidor sencillo.

### Opción 1: abrir directamente

- Abre `index.html` en tu navegador favorito.

### Opción 2: servidor local

```bash
cd PaginaDeRecetas
python -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```
